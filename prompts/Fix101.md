# Inventory Page — UI/UX & Functionality Improvements

Implement the following changes to the Inventory page to improve its usability, organization, and product management workflow.

## 1. Product Enrollment Modal

* When the user clicks Add Product, open a popup modal containing the product enrollment form.

* Do not insert the product entry directly into the existing page.

* Include all necessary product fields, including:

  * Product Logo/Icon

  * SKU (required and unique)

  * Product Name

  * Category

  * Quantity

  * Purchase Price (Unit Price)

  * Selling Price

## 2. Product Icon & Pricing

* Replace the existing product image column with a Product Logo/Icon column.

* Allow users to upload a small product logo or icon to visually identify each product.

* Introduce a new Selling Price field and column.

* Clearly distinguish between:

  * Unit Price: The purchase price or cost of acquiring the product.

  * Selling Price: The actual price at which the product is sold.

Both prices should be available in the product enrollment form and product details.

## 4. Three-Dot Actions Menu

Implement a three-dot action button in the Actions column.

When clicked, display the following options:

* Details: Open a popup modal displaying all relevant product information.

* Edit: Allow the user to modify the product information.

* Delete: Allow the user to delete the product.

### Product Details Modal

* Display all relevant information associated with the selected product.

* Include an Edit button in the top-right corner of the modal.

* When clicked, allow the user to edit the product details.

Keep the main inventory table minimal while making all additional information accessible through the details modal.

## 5. Sorting & Filtering

Retain the existing sorting and filtering functionality, but improve the visual presentation.

### Filtering

* Allow users to filter products by category.

* Use a funnel icon for the filtering control.

### Sorting

- Allow users to sort products by:

* Alphabetical order (A–Z / Z–A)

* Stock quantity

* Low-to-high and high-to-low values, where applicable.

- Use a dedicated sorting icon for the sorting control.

Ensure the sorting and filtering controls are intuitive and easy to access.

## 6. SKU Validation — Required

The SKU field must be mandatory and unique for every product.

* Do not allow users to create a product without an SKU.

* Prevent duplicate SKUs.

* Enforce SKU uniqueness at the database level, not just in the frontend.

The SKU will act as the unique identifier for each product.

## Implementation Objective

Implement these changes as a coding agent, ensuring that the Inventory page has a clean, minimal table, a modal-based product enrollment workflow, accessible product details, and reliable SKU validation.

Preserve the existing sorting and filtering functionality while improving the UI and maintaining consistency with the application's existing design system.

Fix this issue so that:

* Newly created items are correctly added to the inventory list after successful submission.

* The inventory list refreshes or updates immediately without requiring a manual page reload.

* The frontend state remains synchronized with the database.

* Appropriate success and error feedback is displayed to the user.

Ensure that the item creation workflow works reliably from submission to displaying the newly created item in the inventory table.
