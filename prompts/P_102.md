### Part C — Accounts: Edit Entries + Convert Add Forms to Modals

**Target:** `src/app/(management)/accounts/page.tsx` + new modal file

#### C1. Create `src/components/accounts/AccountEntryModal.tsx`

Props:
```typescript
{
  type: 'expense' | 'income';
  entry?: AccountEntry;     // present = edit mode, absent = add mode
  onClose: () => void;
  onSave: (entry: AccountEntry) => void;
}
```

Modal title: `"Add Expense"` / `"Edit Expense"` / `"Add Income"` / `"Edit Income"` — derived from `type` + whether `entry` is provided.

Form fields in order:
- **Date** — date input, default `getTodayIST()`
- **Description** — text input, required
- **Category** — dropdown; expenses draw from `EXPENSE_CATEGORIES` + user custom expense categories; income draws from `INCOME_CATEGORIES` + user custom income categories. Do NOT cross-pollinate these lists
- **Method** — pill selector: Cash | UPI | Card | Other, default Cash. Same pill style used in RenewModal
- **Amount** — number input, required
- **Notes** — optional single-line text input

Edit mode: pre-fill all fields from `entry`. Add mode: all fields empty/default.

On confirm: call `onSave` with a fully constructed `AccountEntry` (generate `id: Date.now().toString()` for new entries, preserve `entry.id` for edits).

#### C2. Replace inline add forms with modal triggers

Remove the inline expanding add-form blocks entirely — the `showAddExpense` and `showAddIncome` boolean states and their JSX. The "Add Expense" and "Add Income" buttons now only set modal open state:

```typescript
const [showExpenseModal, setShowExpenseModal] = useState(false);
const [showIncomeModal, setShowIncomeModal]   = useState(false);
const [editingEntry,    setEditingEntry]      = useState<AccountEntry | null>(null);
const [editingType,     setEditingType]       = useState<'expense' | 'income'>('expense');
```

"Add Expense" button → `setShowExpenseModal(true)`
"Add Income" button  → `setShowIncomeModal(true)`

#### C3. Add Pencil icon to each row

In the Expenses table and Income table, in the ACTIONS cell, add a `Pencil` icon (lucide-react, size 15, `text-so-muted hover:text-so-accent cursor-pointer`) to the left of the existing `Trash2` icon.

Expense row pencil click:
```typescript
setEditingType('expense');
setEditingEntry(entry);
```

Income row pencil click:
```typescript
setEditingType('income');
setEditingEntry(entry);
```

#### C4. Render all modals at the bottom of the page JSX

```tsx
{showExpenseModal && (
  <AccountEntryModal
    type="expense"
    onClose={() => setShowExpenseModal(false)}
    onSave={(e) => { mockExpenses.push(e); setShowExpenseModal(false); refresh(); }}
  />
)}

{showIncomeModal && (
  <AccountEntryModal
    type="income"
    onClose={() => setShowIncomeModal(false)}
    onSave={(e) => { mockIncome.push(e); setShowIncomeModal(false); refresh(); }}
  />
)}

{editingEntry && (
  <AccountEntryModal
    type={editingType}
    entry={editingEntry}
    onClose={() => setEditingEntry(null)}
    onSave={(updated) => {
      const arr = editingType === 'expense' ? mockExpenses : mockIncome;
      const idx = arr.findIndex(e => e.id === updated.id);
      if (idx !== -1) arr[idx] = updated;
      setEditingEntry(null);
      refresh();
    }}
  />
)}
```
